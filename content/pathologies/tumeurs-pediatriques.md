- Différences **cancer enfant vs adulte**
- Connaître les **syndromes de prédisposition**
- Comprendre la **variabilité des présentations cliniques**
- Principes généraux de **prise en charge**


| | **Enfant** | **Adulte** |
|---|---|---|
| **Prévalence** | Rare (15'780 cas/an US) | Fréquente (1'658'370/an US) |
| **Âge au Dx** | 6 ans | 67 ans |
| **Mutations somatiques** | Limitées | Abondantes |
| **Origine** | **Embryonnaire**, altérations développement | **Liées au vieillissement** |
| **Génétique** | **Anomalies congénitales** (LFS, NF1, RB1), influences périnatales (âge maternel, T21) | Accumulation progressive de mutations, **facteurs environnementaux** (tabac, alcool, pro) |
| **Microenvironnement** | Biologique en **croissance** | Vieillissement |
| **Conséquences LT** | <font color="#ff0000">**Effets secondaires LT importants**</font> (croissance, cognition, fertilité) | Survie immédiate prioritaire |
| **Recherche clinique** | Budget **4%** NCI, essais difficiles, **11 médicaments approuvés 1980-2017** | 96% budget NCI |


| | **Enfant** | **Adulte** |
|---|---|---|
| **Mutations génétiques** | Moindres → gènes du **développement embryonnaire** (facteurs transcription, régulateurs chromatine) | Plus fréquentes → pathways cellulaires |
| **Instabilité génomique** | Moindre → <font color="#ff0000">**translocations chromosomiques spécifiques**</font> | Instabilité importante (mutations accumulées) |
| **Croissance incontrôlée** | Signaux du développement | Signaux de division/croissance |
| **Évasion apoptose** | Mécanismes de survie embryonnaires | Inactivation pathways apoptose |
| **Métastase** | Mécanismes embryonnaires | **Transition épithélio-mésenchymateuse** |
| **Altération métabolique** | Ressemble aux changements embryonnaires | Sucres, lipides, acides aminés |


- **Leucémies** → <font color="#ff0000">**ETV6 (chr 12) + RUNX1 (chr 21)**</font>


- **360 cas/an** en Suisse, **2/3 chez les enfants < 15 ans**
- Registre Suisse Cancer Enfant (RSCE 2013-2022)


- <font color="#ff0000">**Tumeurs SNC : ~24%**</font>
- <font color="#ff0000">**Leucémies : ~22,5%**</font>
- **Lymphomes : ~16%**
- Autres épithéliales/mélanomes : 12%
- **Sarcomes tissus mous : 5,7%**
- **Tumeurs germinales : 5,6%**
- **Tumeurs osseuses : 4,6%**
- **Neuroblastomes : 4,1%**
- **Tumeurs rénales : 3,3%**
- **Rétinoblastomes : 1,4%**
- Tumeurs hépatiques : 1%


- <font color="#ff0000">**< 5 ans**</font> → **leucémies**, **neuroblastomes**, **rétinoblastomes**
- **Leucémies** → tous âges mais surtout < 5 ans
- **Lymphomes** → prévalence augmente progressivement avec l'âge
- <font color="#ff0000">**Tumeurs osseuses** → grands enfants (**pic de croissance**)</font>


- **Autosomique dominante**, variants du gène **NF1 (17q11.2)**
- **Incidence ~1:3000**
- <font color="#ff0000">**50% hérité / 50% de novo**</font>
- **Espérance de vie ↓ de 8-15 ans**

**Pathogénèse**
- Gène NF1 → code pour la **neurofibromine**
- Neurofibromine = **inhibiteur de l'activité Ras (MAPK)** → régulateur clé G1→S
- <font color="#ff0000">**Perte biallélique NF1 → ↑ activité Ras pro-oncogène**</font>
- Explique vasculopathies + troubles mémoire chez NF1

**Critères cliniques (≥ 2)**
- **≥ 6 TCALs** (taches café-au-lait) ≥ 5 mm prépubère / ≥ 15 mm postpubère
- **≥ 2 neurofibromes** ou **≥ 1 neurofibrome plexiforme**
- Taches de rousseur axillaires/inguinales
- **Gliome des voies optiques (GVO)**
- **≥ 2 nodules de Lisch** (hamartomes iris)
- Lésion osseuse (dysplasie aile sphénoïde / os longs)
- **Parent 1er degré** avec NF1

**Tumeurs associées**
- Neurofibrome cutané **~100%**
- Neurofibromes plexiformes **25%**
- **LGG/OPG** : 15-20%
- **MPNST** (malignant peripheral nerve sheath tumor) : 8-13%


- <font color="#ff0000">**Mutation TP53**</font> → inactivation du **p53** (gène suppresseur de tumeur)
- Sarcomes tissus mous, cancer du sein, multiples néoplasies


- <font color="#ff0000">**Modèle du "two-hit" de Knudson**</font>
- Généralement **1ère mutation héréditaire** + **2ème hit sur le gène sain** (sporadique)
- Formes rares : **2 mutations acquises spontanément**


- **Fatigue, léthargie**
- **Pâleur**
- **Fièvre**
- **Douleurs articulaires / osseuses**
- **Hématomes, pétéchies**
- **Adénopathies**
- **Hépatosplénomégalie**


- **Leucémies** → pancytopénie, adénopathies, HSM
- **Tumeurs cérébrales** → céphalées, vomissements matinaux, troubles visuels/moteurs
- **Ostéosarcomes** → <font color="#ff0000">**plaque cartilagineuse de croissance → fémur distal (genou)**</font>
- **Sarcome d'Ewing** → atteinte **péri-osseuse**, souvent **pelvis**


- **US, CT, IRM**
- **PET-CT** (FDG-18F = analogue du glucose)
- **MIBG** (méta-iodobenzylguanidine = analogue noradrénaline) → **neuroblastomes**


| Tumeur | **AFP** | **β-HCG** |
|---|---|---|
| **Tumeur du sac vitellin** (Yolk sac) | <font color="#ff0000">**+**</font> | -/+ |
| **Choriocarcinome** | -/+ | <font color="#ff0000">**+**</font> |
| **Germinome** | − | -/+ |
| **Tératome** | − | − |
| **Carcinome embryonnaire** | -/+ | -/+ |


- **Gliomes bas grade** → **fibres de Rosenthal**, vaisseaux hyalins
- **Gangliogliomes** → infiltrats lymphoplasmocytaires périvasculaires


- Origine : **gaz moutarde** vers 1940 → ralentit développement cellulaire
- Molécules qui **bloquent le cycle cellulaire**


- <font color="#ff0000">**Largement plus efficace**</font> → cible **plusieurs mécanismes simultanément**
- Standard actuel


- <font color="#ff0000">**Inhibiteurs de voies de signalisation**</font>
- Prescrits **après analyse biologique** de la tumeur
- Exemples : inhibiteurs BRAF, MEK, tyrosine kinase


- **Bevacizumab** (mab anti-VEGF)
- **Blinatumomab** (bispécifique **CD3-CD19**)
- **Mosunetuzumab** (bispécifique CD3-CD20)


- **Chirurgie** (± guidée par MIBG pour neuroblastome)
- **Chimiothérapie intra-artérielle sélective**
- **Radiothérapie** → photons vs **protons** (meilleure épargne tissus sains, préférée en pédiatrie)


- <font color="#ff0000">**Risques neurocognitifs**</font> → tumeurs cérébrales + LLA traitée par chimio
- **Troubles croissance + développement**
- **Troubles de fertilité**
- **Cardiotoxicité** (anthracyclines)
- **Néoplasies secondaires**
- **Endocrinopathies**


- Cancer enfant = **maladie rare, différente de l'adulte** (origine embryonnaire, translocations spécifiques)
- **Formes héréditaires** peuvent s'exprimer à l'âge pédiatrique (**NF1, Li-Fraumeni, RB1**)
- **Présentation clinique variable** selon type, localisation, âge
- **Anomalies génétiques/moléculaires** → importantes pour **Dx, pronostic, traitement**
- **< 5 ans** : leucémies, neuroblastomes, rétinoblastomes
- **Grands enfants** : tumeurs osseuses (pic de croissance)
- **Ostéosarcome** → genou (fémur distal) ; **Ewing** → pelvis péri-osseux
- **AFP** → sac vitellin ; **β-HCG** → choriocarcinome
- Pronostic global amélioré mais <font color="#ff0000">**effets à long terme majeurs sur QoL**</font>
